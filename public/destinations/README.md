# Destination images

Copy the destination images from the **education** project so the visit visa carousel and destination cards show the same photos:

- From: `proconsulting_education/public/destinations/`
- To: this folder (`proconsulting_immigration/public/destinations/`)

Required files (same names as in education):  
`UK.webp`, `Canada.webp`, `Australia.webp`, `USA.webp`, `France.webp`, `Spain.webp`, `Sweden.webp`, `Ireland.webp`, `new_zealand.webp`

If a file is missing, the carousel falls back to the flag icon on a gradient background.
