# Native appointment booking

The worktrees contain native appointment creation, a scoped booking endpoint and retry protection. Staff select an assigned enquiry, enter the meeting time and duration and can open the saved appointment directly.

The local CRM verification passed typecheck, 193 tests and production build. The mobile API integration covered assigned and foreign enquiries, overlapping requests, two concurrent bookings for one slot, a lost write acknowledgement, audit completion retry and replay after cancellation.

Mobile typecheck, lint, 12 tests and Android/iOS JS exports passed. Chrome component checks exercised the form with simulated native controls, cache-clear failure, identical retry, opening the confirmed record and returning to the list. Physical-phone acceptance remains pending.

During implementation, the conflict fixture inherited a closed status and the first automatic calendar load failed mobile lint. Both were corrected and the relevant checks passed on rerun. No production deployment or OTA publication was verified. The mobile checkout has no Git remote.
