# Blog Studio authoring

CMS-05 adds visual links, captioned images, tables with header cells, subheadings and quotes. Editorial staff can select published media for the article or cover, edit cover alternative text, and inspect an unsaved reader preview and search snippet. Draft, review, schedule, publish, archive and revision actions use the existing services.

The CMS regression saves headings, links, quotes, captioned images and tables, restores cover alternative text, preserves imported tags and rejects unsafe metadata replacement. All 193 tests, typecheck and production build passed.

Isolated Chrome exercised media upload/publication and selection, slug override, link validation, rich blocks, search snippet, sanitized reader preview, scheduling controls and saving/reopening a review post. The editor fit a 393px viewport. The first browser run exposed an ambiguous picker label. The control now has an explicit accessible name. A later test locator for the source textarea was corrected before the passing run.

The preview used synthetic records. The local server was stopped after verification. No live post, VPS, mobile binary or public blog provider was changed.
