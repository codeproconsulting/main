# MOB-01 React Native staff app

The mobile app lives in the sibling `Proconsulting-App` folder. Its own context vault records the app source, build profiles, build artifacts and device acceptance. The mobile app uses the existing CRM screens in a native browser view and keeps authentication and Appwrite access on the CRM server.

The CRM profile and sign-out control are now available at phone widths. A synthetic 390-pixel browser check verified sign-in and sign-out. Live mobile sign-in requires the correct TLS certificate at the CRM hostname and the deployed CRM release.
