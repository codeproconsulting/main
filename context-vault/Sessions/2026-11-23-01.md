# Offline appointment agenda

After a successful online refresh, the saved agenda is available from the native workspace. The screen displays the last sync time and hides meetings that have ended. Reconnect and refresh after a booking change.

Synthetic API checks cover chronological order, the 12-meeting bound, booked status, current appointment and enquiry ownership for counsellors and managers, legacy response shape, optional query failure and access denial. CRM typecheck, 193 tests and production build passed.

Mobile typecheck, lint, 12 tests and Android/iOS bundle exports passed. SecureStore tests cover older snapshots, malformed agenda, refresh replacement, expiry and storage limits. A Chrome workspace interaction check with simulated native controls covered offline restart, read-only display, foreground hiding, expiry, sign-out and invalidation before a calendar write. The first foreground-hide check sampled before React finished rendering. Repeating the check while waiting for the rendered change passed.
