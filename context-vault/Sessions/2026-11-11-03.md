# CONSULT-01 consultation tracking

Open a lead and select **Consultations** to log a completed session. Enter the destination and consultation date. Managers select the counselor who held the session. Counselors can log their own work on assigned enquiries.

**Reports → Consultation tracking** lists the customer enquiry, counselor, destination and date. Filter by counselor, destination or both to see the matching count. Credit remains with the recorded counselor after a lead handoff. Each row counts one session, so repeat sessions on the same enquiry count separately.

Before rollout, preview `node scripts/setup-appwrite.mjs --only=consultations`, apply the private schema with the setup key, and verify the indexes and both report filters with synthetic records. The current Appwrite check was read-only. See [[Session Wall]] and [[06 Deployment]].
