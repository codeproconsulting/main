# Native personal reminder inbox

Staff can open their current follow-up, meeting and application reminders, acknowledge a reminder as read and jump to its native detail screen. The screen displays source times in Karachi time. A stored page can contain only outdated notices, so a continuation stays usable even when the visible list is empty.

Synthetic mobile API checks covered sign-in, cursor validation, empty pages with a continuation, recipient isolation, stale and reassigned records, all three linked source IDs and event times, repeated acknowledgement and unchanged task status. CRM typecheck, 193 tests and production build passed.

Mobile typecheck, lint, 13 tests and Android/iOS bundle exports passed. A Chrome interaction check using the native components with simulated controls covered empty pages, previous/next, all three linked record types, returning to the same page, read acknowledgement, lost response recovery, backgrounding, offline state, access denial and sign-out.

Mobile commit `59a0399` is local to `codex/mobile-staff`, which has no configured remote. The CRM API must reach the VPS before publishing a compatible mobile update. Physical-phone verification, VPS rollout and OTA publication are pending.
