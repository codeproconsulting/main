# Native lead activity

Staff can expand recent conversation history in the online native lead editor. The web and mobile server paths now share event visibility and field selection. The phone displays ten rows at a time and clears the history on hide or background.

Integration checks exercised both web and mobile loaders, empty history, newest-first order, role-specific event and author visibility, cross-entity ID collisions, malformed details, no-store responses, revoked sessions and reassignment. CRM typecheck, 193 tests and production build passed.

Mobile typecheck, lint, 13 tests and Android/iOS exports passed. A Chrome interaction check with simulated native controls exercised deferred loading, Karachi time, older entries, refresh, empty and failed reads, backgrounding, a late response after hiding, access loss, cache exclusion and a server without timeline support.

An initial integration-test run stopped on a duplicate fixture variable. The first browser timestamp assertion also matched several rows. Both test checks were corrected and rerun successfully.

Mobile commit `7914a0a` is local to `codex/mobile-staff`, which has no remote. VPS rollout, OTA publication and physical-phone checks remain pending.
